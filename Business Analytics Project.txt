# BUSI1783 Business Analytics Project

## Project Overview

This project analyses retail shopping behaviour using questionnaire data collected from respondents. The analysis focuses on identifying patterns in shopping behaviour, brand loyalty, promotional sensitivity and product category variety.

The project applies statistical and analytical techniques including descriptive statistics, reliability analysis, correlation analysis, Principal Component Analysis (PCA), K-Means clustering, cluster profiling, Welch's ANOVA, Games-Howell post-hoc comparisons, demographic analysis and shopping-channel analysis.

## Dataset

The dataset used for the analysis is provided in:

`working sheet.xlsx`

The dataset contains questionnaire responses covering demographic characteristics, retail shopping behaviour, brand loyalty, promotional sensitivity, product category variety and shopping-channel preferences.

## Notebook

The complete analysis was conducted using Python in a Jupyter Notebook.

The notebook containing the analysis and results is:

`analysis (1).ipynb`

The notebook includes the data preparation, statistical analysis, clustering procedures, visualisations and results used for the project.

## Main Analytical Methods

- Descriptive statistics
- Cronbach's Alpha reliability analysis
- Pearson correlation analysis
- Principal Component Analysis (PCA)
- Kaiser-Meyer-Olkin (KMO) test
- Bartlett's Test of Sphericity
- K-Means clustering
- Elbow method
- Silhouette analysis
- Cluster profiling
- Welch's ANOVA
- Games-Howell post-hoc comparisons
- Demographic analysis
- Shopping-channel analysis
- Chi-square tests
